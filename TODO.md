# cjoka Engine -- Roadmap & Optimization TODO

## Этап 1: Жестчайшая Оптимизация (Hardcore Optimization) - **[ТЕКУЩИЙ]**
Текущий конвейер рендеринга отправляет на отрисовку всё подряд. Нам нужно радикально срезать нагрузку на CPU и GPU перед добавлением тяжелых визуальных фич.
- [ ] **Frustum Culling (Отсечение невидимого)**: Реализовать AABB (Bounding Box) для всех мешей. Отсекать объекты за пределами пирамиды видимости камеры до отправки на GPU.
- [ ] **Shadow Culling**: Отсекать объекты, которые не попадают в камеру теней. (Сейчас в тень рендерится вообще вся сцена).
- [ ] **Transform Caching**: Избегать пересчета `glm::mat4 model` каждый кадр, если объект не двигался (опционально, проверить профайлером).
- [ ] **State Sorting / Уменьшение Draw Calls**: Группировать объекты по материалу/шейдеру перед отрисовкой для минимизации смены состояний OpenGL.

## Этап 2: Конвейер Освещения (Forward+ Clustering) - **[ВЫПОЛНЕНО]**
Переход от наивного Forward к современному Forward+.
- [x] **Compute Shader**: Создан Compute Shader для разбиения экрана на 3D-кластеры.
- [x] **Light SSBO**: Перенесены параметры Point Light в SSBO.
- [x] **Light Culling**: Реализовано отсечение света по AABB кластеров.
- [x] **LitFS Update**: Обновлен `kLitFS` и `kLitInstancedFS` для чтения индексов из SSBO. Лимит в 16 источников снят, теперь поддерживается 1024.

## Этап 3: Тени и Сглаживание (Shadows & TAA) - **[ВЫПОЛНЕНО]**
Подготовка к высококачественному рендерингу больших пространств.
- [x] **Cascaded Shadow Maps (CSM)**: 3 каскада (Near, Mid, Far) с рендером в `GL_TEXTURE_2D_ARRAY`.
- [x] **PCSS / 16-tap Poisson Filtering**: Мягкие тени с переменным радиусом и адаптивным смещением без ступенчатости и артефактов.
- [x] **Temporal Anti-Aliasing (TAA)**: Временное сглаживание на базе YCoCg AABB-Clamping с репроекцией истории по буферу глубины, устраняющее мерцание граней и спекулярный шум.

## Этап 4: Некстген GI (Voxel Cone Tracing - VXGI)
Глобальное освещение и отражения.
- [ ] **Voxelization Pass**: Compute/Geometry шейдер для записи сцены в 3D текстуру (Clipmap вокруг камеры).
- [ ] **Voxel Mipmapping**: Анизотропная генерация мип-уровней для вокселей.
- [ ] **Cone Tracing (GI)**: Трассировка диффузных конусов для глобального освещения.
- [ ] **Cone Tracing (Reflections)**: Трассировка узкого конуса для глянцевых отражений на асфальте и машинах.
