# cjoka Engine — ROADMAP (v0.48 BETA → v0.60)

> Цель движка: универсальный C++20 / OpenGL 4.6 рендер с открытым миром,
> ночным/дождевым GI и отражениями. Игры строятся поверх движка отдельно.
> Целевая игровая демка: курируемый город-район, вождение, ~13 миссий, сюжет 2-4ч.

## Схема версионирования
- `x.y`  — feature-релиз (новые возможности).
- `x.yz` — post/beta-патч (напр. `0.50a`, `0.51b`) — стабилизация и доработка
  предыдущего релиза, без новых крупных фич.

---

## Принципы (универсальность движка)
- Всё, помеченное «универсальное» — **инфраструктура движка**, переиспользуемая любой игрой.
- Миссии, сюжет, пешеходы, трафик, хэндлинг, звуки, контент — **слой конкретной игры** (строится отдельно поверх движка).
- Движок даёт дженерик-кирпичи: ECS, физика (PhysX/Vehicle/NavMesh), AI-примитивы, Trigger/Event,
  Save/Load, скриптинг API, аудио-API, Material-система. Игра собирает из них свой контент.
- **Материалы, не шейдеры**: авторинг = PBR-параметры + текстуры (`Material`, `Components.h:72`).
  Shader Graph (0.60) расширяет материалы кастомным фрагментом, НЕ заменяя PBR-базу
  (нет графа → стандартный PBR; есть → сгенерённый фрагмент).
- Каждый релиз проверяется на: не зашита ли игровая логика в движок.

## Стратегия ассетов / Моддинг / Steam-обновления  **[ОПЦИОНАЛЬНО]**
> Ассеты НЕ зашиваются в бинарь. Иначе убиваются моды, удобство и скорость обновлений (Steam качает exe целиком).
> **Статус:** базовое требование (ассеты уже вне бинаря) ВЫПОЛНЕНО. Пакинг в `.pkg` + VFS/mount-слой — **опциональная полировка** под моддинг и Steam-дельту, НЕ блокирует релиз. Делается когда удобно.
- **Текущее (аудит):** меши/текстуры/сцены — внешние файлы (`Assets::Mesh(path)`, `Assets::Texture(path)`, `assets/*.json`); стендалон ссылается на `assets/`, не эмбедит. Шейдеры (`DefaultShaders.h`) зашиты как строки — это код движка, допустимо.
- **Принцип:** пользовательский контент (меши, текстуры, сцены, материалы из Shader Graph 0.60) — всегда внешние файлы. Бинарь = только код + редактор.
- **Формат .pkg по категориям** (рядом с бинарём, папка `assets/`): `textures.pkg`, `meshes.pkg`, `audio.pkg`, `scenes.pkg`, `materials.pkg` … Правка текстур инвалидирует только `textures.pkg`, а не весь контент. Реализация — простой свой заголовок+оглавление+блобы, либо ZIP-совместимый (PhysFS/minizip).
- **Текстурные форматы (GPU-compressed BCn) — обязательно для перфа:** конвертировать ВСЕ текстуры в BCn на этапе билда ассетов, НЕ в рантайме. Маппинг: albedo без альфы → **BC1** (4 bpp), albedo+альфа → **BC3** (8 bpp), нормали → **BC5** (2-канала, без потери XY), roughness/metal/AO (упакованы в 1 текстуру) → **BC4/BC5**, высококачественный цвет/эмиссив → **BC7**. Результат — `.dds(BCn)` внутри `textures.pkg`, грузится напрямую в VRAM без декомпрессии. Экономия VRAM до 8× (BC1 vs RGBA8) — критично для 3050/6 ГБ. Запретить грузить сырые PNG/JPG как RGBA8 в проде.
- **Моддинг через mount-порядок:** VirtualFileSystem монтирует с приоритетом
  `loose assets/` > `mods/<name>/*.pkg` > `assets/*.pkg` (база). `AssetManager` резолвит путь по этому порядку — мод перекрывает базу, не трогая оригинал.
- **Steam-дружественность:** каждый `.pkg` — отдельный файл депо → при правке текстур редownload только `textures.pkg` (дельта, не весь exe). Категорийное дробление = минимальный размер патча.
- **Стендалон-билдер (0.58):** явно запретить эмбед ассетов; копировать/симлинкать `assets/` рядом с бинарём.
- **Shader Graph (0.60):** сгенерённые материал-шейдеры грузить с диска / компилировать в рантайме, не зашивать.

## v0.48 BETA — текущее состояние (аудит)
**Реально работает:**
- Forward+ compute light culling, PBR+IBL, 3-cascade CSM, SSR (вкл), Bloom+ACES.
- Скиннинг 128 костей + FBX (меши, скелет, клипы анимации).
- Редактор: gizmo, Play Mode, сериализация JSON, окна Alt+1..8, Asset/Material Browser,
  drag&drop, Standalone Builder.
**Не доделано (найдено аудитом):**
- ClusterLOD написан (`SelectLODs`), но НЕ заматчен в рендер → не работает в кадре.
- TAA / GTAO / Volumetric Fog / z-prepass — написаны, но ВЫКЛЮЧЕНЫ по умолчанию.
- Undo/Redo в редакторе — отсутствует.
- Нет стриминга, бейка света, VXGI, Light Probes, геймплей-фреймворка.

## v0.50 — FLAGSHIP (самые крутые фичи) [ВЫПОЛНЕНО ✅]
Тема: **Open World + Next-Gen Lighting**. Без этого красивый город не поедет и не заблестит.
- [x] **ClusterLOD в рендер-путь** — `SelectLODs` → кластерный MultiDraw (Nanite-подобная кластеризация).
- [x] **Инстансинг** общих мешей (`kLitInstancedVS`) — здания/парковки за 1 draw call.
- [x] **Стриминг мира** — чанки по сетке, load/unload по радиусу камеры, fade pop-in.
- [x] **VXGI** — динамический GI (3D clipmap + voxel cone tracing) — Lumen-лайк, ночь/отскоки.
- [x] **Ночь/Дождь/Отражения** — wetness-материал (roughness по дождю) + SSR на мокром асфальте.
- [x] **Включить + отладить** TAA / GTAO / Volumetric Fog (включены по умолчанию, без гостинга и бандинга).
- [x] **Baked Mixed Lighting + Light Probes** — запечь статику города + приём GI динамикой через пробы.
